四种转码模式

许仙转码授权平台把日常遇到的编码、加密数据统一收进一个输入框，按数据类型切换模式即可，全部在浏览器本地完成计算。

  • 腾讯 —— 解析腾讯 qzapp 授权码，还原 access_token、openid、pay_token 等字段。
  • JSON —— 自动截掉前后杂质，格式化成缩进结构，统计键值数量。
  • Base64 —— 解码任意 Base64 串，自动判断 UTF-8 或二进制，并做回编码校验。
  • 密钥 —— AES-GCM 双向运算，密文自动解密、明文自动加密。

腾讯授权码是怎么组成的

这类授权码本质是一段被包了两层的查询串，结构固定，因此可以完整还原：

t          = URLSearchParams(fields).toString()
pasteboard = base64(t)
url        = tencent{appid}://qzapp/mqzone/0?objectlocation=url&pasteboard={pasteboard}
enterCode  = "MOCK." + base64(url)

字段顺序为 access_token / openid / pay_token / expires_in / encrytoken / pf / pfkey / ret。把上面的链路倒过来走一遍，就是「解析」；正着走，就是「生成」。

可以接受的输入形态

  • 完整链接：tencent1111677210://qzapp/mqzone/0?objectlocation=url&pasteboard=...
  • 带前缀的授权码：MOCK.dGVuY2VudDEx...
  • 裸 pasteboard base64 串
  • 裸查询串：access_token=...&openid=...

操作步骤

  1. 在上方四个标签里选择数据类型。
  2. 把原始数据粘贴进「数据解析」输入框。
  3. 点「开始解析」，结果区会给出解码内容与逐条处理轨迹。
  4. 解析出的字段会列成明细表，单行可复制；底部四宫格可一键复制整份结果或原始数据。

密钥模式说明

密钥派生与加密参数和主流实现保持一致：

key = SHA-256(passphrase)          // 32 字节
iv  = random(12)                   // 前置到密文之前
out = base64(iv || AES-GCM(key, iv, plaintext))
同一段密文用错误密钥解密会被 GCM 认证直接拒绝，不会返回乱码，这一点可以用来判断密钥是否正确。

OP/Auth 与风控自检

OP/Auth 按钮会把当前字段组装成三种常见形态：Query 串、openid|access_token 管道串、以及 Basic Base64 头，方便直接贴进调试工具。

做违规 按钮执行字段体检：检查凭证是否齐全、expires_in 折算剩余天数、token 长度是否合理、ret 是否成功，最后给出放行或回退建议。
