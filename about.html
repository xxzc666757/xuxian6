关于本站

许仙转码授权平台是一个纯前端的在线转码工具，把常见的授权码解析、编码转换、对称加解密收在同一个界面里，省去在不同站点之间来回切换的麻烦。

技术构成

  • 界面：原生 HTML + CSS，无框架、无构建步骤，首屏直出。
  • 转码内核：单个 engine.js，约 15 KB，零依赖。
  • 加密：浏览器原生 Web Crypto（crypto.subtle），AES-GCM 256 位。
  • 存储：仅使用 localStorage 记录本机授权标识与解析次数。
  • 网络：页面不发起任何外部请求，可离线运行。

支持的格式

腾讯 qzapp   tencent{appid}://qzapp/...?pasteboard={base64}
JSON         任意对象 / 数组，允许前后带杂质
Base64       标准与 URL-safe，自动补齐 padding
AES-GCM      base64(iv[12] || ciphertext)，SHA-256 派生密钥

设计说明

界面沿用深色紫黑配色与玻璃卡片层，背景支持自定义壁纸；信息层级按「授权状态 → 输入 → 结果 → 快捷操作」四段排列，单手可完成全部操作。
