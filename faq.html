常见问题

数据会被上传到服务器吗？

不会。解析、编解码、AES-GCM 运算全部由浏览器内的 Web Crypto 与 JavaScript 完成，页面没有发起任何网络请求，断网也能正常使用。

需要登录或卡密吗？

不需要。打开即用，授权卡显示的是本机生成的标识码，存在浏览器 localStorage 里，清缓存后会重新生成。

为什么解析腾讯授权码提示「无法识别」？

常见原因有三个：字符串被聊天软件截断（末尾少了字符）、复制时混入了空格与换行、或者粘贴的其实不是 qzapp 结构。可以先清空再整段重新复制一次。

Base64 解出来是乱码怎么办？

说明原始内容是二进制而不是文本。结果区会标注「latin1」，此时看到的是字节的原始映射；如果这是加密数据，请改用「密钥」模式。

密钥模式加密出来的密文能解回去吗？

可以。把密文粘回输入框、填同一个密钥再点解析，会自动识别为解密方向并还原明文。换一个密钥则会因 GCM 认证失败而报错。

支持批量处理吗？

当前版本为单条解析，一次处理一份数据。需要连续处理时，解析完一份直接点「清空内容」再贴下一份即可。

手机上能用吗？

可以。页面按移动端优先设计，iOS Safari 与 Android Chrome 都支持，复制按钮在小屏上同样可用。

页面上的版本号 v20261112 是什么？

是转码内核的版本标记，用于区分协议实现的迭代。每次调整解析规则都会同步更新这个号。

解析结果可以直接分享吗？

结果里可能包含账号凭证，分享前请自行确认接收方。工具本身不保存、不上传任何解析内容，关闭页面即清空。
